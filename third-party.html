AiRi / ViriTTS is built on open-source software and integrates with third-party services. This page acknowledges the major components that make up the application and the commercial services it integrates with.

Desktop Application Framework

  • Tauri — MIT / Apache-2.0. Desktop application shell (Rust + system WebView) powering the AiRi UI.
  • Rust — MIT / Apache-2.0. Language and toolchain used by the Tauri shell.
  • Microsoft Edge WebView2 — Microsoft Software License. Embedded browser runtime used on Windows to render the application UI.
  • Python — Python Software Foundation License. Runtime and standard library for the AiRi backend sidecar.

AI Model Providers (Commercial APIs)

Usage of these services is subject to each provider's own Terms of Service.

Local AI / Vision
